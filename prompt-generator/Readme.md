# AI Prompt Generator

一个简洁高效的需求管理工具，帮助你整理和导出 AI 提示词需求清单。

## 功能特性

- **需求管理**：添加、编辑、删除、排序需求条目
- **优先级标记**：高/中/低三级优先级
- **标签分类**：使用标签组织需求
- **文件关联**：为每个需求添加相关文件路径
- **拖拽排序**：直接拖动卡片调整顺序
- **搜索过滤**：按内容、标签、文件快速查找
- **灵活配置**：可选配置文件编码、提示词、MCP 工具
- **Markdown 导出**：一键导出为标准格式文档
- **数据持久化**：自动保存到本地存储

## 使用说明

### 1. 添加需求

- 在顶部输入框输入需求描述
- 选择优先级（高/中/低）
- 添加标签（可选，逗号分隔）
- 点击"添加"或按 `Ctrl/Cmd + Enter`

### 2. 管理需求

- **完成标记**：勾选复选框标记完成
- **编辑内容**：双击需求文本快速编辑
- **添加文件**：在需求下方输入框添加相关文件路径
- **调整顺序**：拖拽卡片或使用 ↑↓ 按钮
- **删除需求**：点击 × 按钮删除

### 3. 搜索和过滤

使用顶部搜索框按内容、标签或文件名快速查找需求。

### 4. 配置选项

在右侧预览卡片中可配置：

- **配置开关**：选择是否启用文件编码、提示词、MCP 工具
- **文件编码**：支持 UTF-8、GBK、GB2312 等多种编码
- **提示词**：自定义 Markdown 导出的提示内容
- **MCP 工具**：选择需要使用的 MCP 工具（context7、Chrome DevTools 等）

### 5. 导出和复制

- **导出**：下载为 `requirements.md` 文件
- **复制**：复制 Markdown 格式文本到剪贴板
- **清除已完成**：批量删除已完成的需求
- **清除所有**：清空所有需求

## Markdown 输出格式

```markdown
# 需求清单

项目所使用的编码格式：UTF-8

完成下方的任务，完成后按照每个任务给我列出几条我可以改进的内容方案供我选择

共 2 条

- [ ] 新增自定义提示内容输入框 #UI修改 [高优先级]
  - 涉及文件: src/components/Input.vue
- [x] 自定义提示框输入内容 #功能实现 [中优先级]

------
## MCP Tools

use context7
use Chrome DevTools
```

## 技术栈

- **Vue 3**：渐进式 JavaScript 框架
- **Vite**：下一代前端构建工具
- **Pinia**：Vue 状态管理
- **Vue Router**：官方路由
- **Vue I18n**：国际化支持（简体中文、繁体中文、英文）
- **Tailwind CSS v4**：实用优先的 CSS 框架
- **DaisyUI**：Tailwind CSS 组件库
- **vuedraggable**：拖拽排序功能
